# AMETTSA 5.0 Official Brand Assets

Drop the client's PNG files from the Google Drive folder into this directory (`public/assets/brand/`) using their exact filenames. The flyer canvas automatically detects and composites any available PNG assets while falling back cleanly for any omitted files.

Expected filenames:
- `Colour Pallete Ametssa Con.png` (reference palette)
- `Ametssa Bg.png` (1080×1350 background layer)
- `Ametssa Pattern.png` (background pattern overlay)
- `Ametssa and 5_0 Logo.png` (combined AMETTSA & 5.0 emblem/logo)
- `Amettsa 5_0.png` (AMETTSA 5.0 hero lockup)
- `Amettsa Footer.png` (AMETTSA footer strip)
- `Amettsa Socials.png` (social handles lockup)
- `Al-Musaahamah header.png` (top partner/event header)
- `Almusaahamah footer.png` (bottom partner footer)
